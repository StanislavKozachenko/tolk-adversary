# Security Policy

tolk-adversary is a developer tool that reads a contract ABI and writes test
files. It does not run contracts, hold keys, or touch a network.

If you find a vulnerability in the tool itself (for example, a crafted ABI that
leads to code execution when generating tests), please report it privately via
[GitHub Security Advisories](https://github.com/StanislavKozachenko/tolk-adversary/security/advisories/new)
rather than opening a public issue. You can expect an initial response within a
few days.

Vulnerabilities in the contracts you point the tool at are out of scope here —
report those through the relevant project's channel.
